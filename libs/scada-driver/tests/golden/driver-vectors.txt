# Golden vectors of the driver framework: a raw value and a point's rules
# give value bits, quality and flags; an engineering value and a point's
# rules give the raw pattern written (driver interface contract 5.1, 8.4;
# conformance test 5). Bit-identical on x86-64 and ARM64.
#
# The framework's half: raw values are the pattern a protocol assembles
# (after byte order, word order and parts). Each protocol and its simulator
# (#105, #106) add the bytes half to a copy of a line with two fields that
# the framework's test ignores: `bytes=<hex>` (the bytes on the wire) and
# `binding=<text>` (the point's protocol address). Every example is
# invented.
#
# One item per line; `#` starts a comment. Fields are separated by spaces.
#
#   rules <name> <key>=<value>...
#     tag=bool|int64|uint64|float64   the tag's type (required)
#     gain=<decimal> offset=<decimal> binary64 scaling, `{ gain, offset }`
#     gain_i=<int> offset_i=<int>     the same written as integers
#     divide_by=<int>                 `{ divide_by, offset }`
#     marker=<0xhex|nan>[:<FLAG>...]  an invalid marker with action `bad`
#     raw_range=<min>:<max>           `raw_range`
#     enum=<code>,<code>...           an enumeration
#     invert                          a BOOL point read inverted
#     exponent=multiply|divide        `exponent_from` the sample's companion
#     time_from=synced|unknown        `source_time_from` the companion (UTC)
#     device_time=synced|unknown      a time value's `device_time` (UTC)
#     counter=<limit>:<wrap|saturate>:<accept|hold|reset>   a counter
#     double_point=<raw>:<code>,...   `kind: double_point` with `states`
#     substitute=<0xhex>:<value>      an invalid marker with `substitute`
#     keep_last=<0xhex>               an invalid marker with `keep_last`
#     max_age=<seconds>               `max_age`
#
#   sample <rules> raw=<raw>... [companion=<raw>] [bytes=... binding=...] -> value=<value> quality=<Q> flags=<F>,... [source_time=<ns>]
#     A fresh point after attach processes one answer with VALUE per
#     `raw=`, in order, one second apart, at receive times stamped by the
#     driver; the last answer's result is compared. A companion is read
#     with VALUE and GOOD for every answer.
#
#   write <rules> raw_type=<kind>:<width> value=<value> -> raw=<0xhex> written=<value>
#   write <rules> raw_type=<kind>:<width> value=<value> -> refused
#
#   <raw>   signed:<width>:<decimal> | unsigned:<width>:<decimal or 0xhex>
#           | float32:<0xbits> | float64:<0xbits> | bool:<0|1>
#           | time:<nanoseconds since 1970, UTC>
#   <value> int64:<decimal> | uint64:<decimal> | float64:<0xbits> | bool:<0|1>
#   <kind>  signed | unsigned | float | bool
#   <Q>     GOOD | UNCERTAIN | BAD; <F> the flag names of tag database 6, or -
